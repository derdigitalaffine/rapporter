# fam-uh-le

Mobile-first family operating system for collaborative tasks, shopping, routines and public-data integrations.

## Stack
- Django backend
- React + Vite frontend
- PostgreSQL
- PWA
- Docker Compose
- Caddy with automatic Let's Encrypt TLS
- German + English i18n out of the box

## Product principles
- mobile first
- strict usability focus
- modular design system
- privacy by design
- integration-first architecture
