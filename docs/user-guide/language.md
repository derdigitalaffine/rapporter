# Sprache wechseln

Unter **Mehr → Sprache** wechselst du nacheinander zwischen Deutsch, Englisch,
Französisch, Niederländisch und Thai. Nach Thai folgt wieder Deutsch.
Die Auswahl wird auf diesem Gerät gespeichert und nach einem Neustart beibehalten.
Auch die Sprachwahl auf der Anmeldeseite verwendet dieselbe Reihenfolge.
