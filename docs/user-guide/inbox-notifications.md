# Mitteilungen & Benachrichtigungen

FamilyOS trennt zwei Dinge:

- **Mitteilungen** liegen innerhalb der App.
- **Push-Benachrichtigungen** können auf deinem Gerät erscheinen.

## Familienmitteilung senden

Owner, Erwachsene und Teen-Rollen können – sofern die Berechtigung passt – eine Familienmitteilung schreiben.

1. Öffne **Mehr → Mitteilungen**.
2. Wähle **Mitteilung**.
3. Schreibe deinen Text.
4. Wähle **Ganze Familie** oder bestimmte Empfänger.
5. Markiere die Nachricht bei Bedarf als **Wichtig**.
6. Sende sie.

## Mitteilungen filtern

Du kannst den Feed nach **Alle**, **Ungelesen**, **Familie** und **System** filtern.

Bei Systemhinweisen können je nach Meldung direkte Aktionen angeboten werden, zum Beispiel:

- als Aufgabe übernehmen,
- zum Einkauf übernehmen,
- als erledigt markieren.

Eigene Familienmitteilungen können von berechtigten Personen wieder zurückgezogen werden.

## Push auf diesem Gerät aktivieren

1. Öffne **Mehr → Benachrichtigungen**.
2. Lies den kurzen Hinweis.
3. Wähle **Weiter**.
4. Bitte den Browser um die Berechtigung.
5. Erlaube Benachrichtigungen.

Danach kannst du eine Testnachricht senden.

Push gilt immer auch für das jeweilige Gerät bzw. den jeweiligen Browser. Auf einem zweiten Gerät musst du Push deshalb separat einrichten.

## Entscheide, wie viel du sehen möchtest

Du kannst den Detailgrad einstellen:

- nur Wichtiges,
- Zusammenfassung,
- alles.

Zusätzlich lassen sich einzelne Themen ein- oder ausschalten, unter anderem Aufgaben, zugewiesene Aufgaben, Einkauf, Kalender, Familienupdates, Mitteilungen, Routinen und Geburtstage.

## Ruhezeiten

Wenn du nachts keine Pushs möchtest:

1. Aktiviere die Ruhezeit.
2. Lege Start und Ende fest.
3. Prüfe die angezeigte Familien-Zeitzone.

## Browser meldet „blockiert“

Wenn du Benachrichtigungen im Browser bereits abgelehnt hast, kann FamilyOS diese Sperre nicht selbst aufheben.

Öffne die Website-Einstellungen deines Browsers, erlaube dort Benachrichtigungen und lade FamilyOS anschließend neu.
