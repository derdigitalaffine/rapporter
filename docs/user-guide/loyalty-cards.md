# Bonuskarten

Mit Bonuskarten hast du Barcode oder QR-Code an der Kasse schnell griffbereit.

Du findest den Bereich unter **Mehr → Bonuskarten**.

## Karte öffnen

1. Öffne **Bonuskarten**.
2. Wähle die Karte.
3. Tippe auf die große Kassenansicht bzw. Vollbild.
4. Zeige den Code an der Kasse vor.

Der Code wird lokal im Browser dargestellt.

## Karte finden

Nutze die Suche, wenn du mehrere Karten gespeichert hast. Favoriten helfen dir zusätzlich, wichtige Karten schnell wiederzufinden.

## Offline an der Kasse

Bereits synchronisierte Bonuskarten werden lokal für die Offline-Nutzung vorgehalten.

Das bedeutet: Wenn du im Laden plötzlich keinen Empfang hast, kannst du eine bereits geladene Karte weiterhin öffnen.

Im Offline-Modus kannst du die Karte allerdings nicht normal bearbeiten oder neu synchronisieren.

## Neue oder geänderte Karte vor dem Einkauf synchronisieren

Wenn du eine Karte gerade erst angelegt oder geändert hast, öffne Bonuskarten einmal mit Internetverbindung und synchronisiere. So stellst du sicher, dass der aktuelle Stand auf dem Gerät liegt.
