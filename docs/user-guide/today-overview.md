# Heute

Neue oder bewusst zurueckgesetzte Ansichten beginnen mit einem kompakten
Ueberblick: Aufgaben fuer heute, heutige Kalendertermine, offene Einkaufsartikel,
sichtbare Pinnwand-Pins und ungelesene Messenger-Nachrichten. Jede Kachel oeffnet
den zugehoerigen Bereich. **Alle Bereiche** fuehrt zur gesamten App.

Unter **Wichtig** stehen hoechstens drei relevante Aufgaben oder Warnungen.
Konkrete Terminueberschneidungen und nicht verfuegbare Quellen werden separat
kenntlich gemacht. Eine nicht verfuegbare Zahl bedeutet nicht, dass nichts offen ist.

Deine bisher gespeicherte Ansicht bleibt unveraendert. Ueber das Stiftsymbol
**Anpassen** kannst du den Ueberblick hinzufuegen sowie Tagesverlauf, Woche und
weitere Widgets waehlen. **Standard wiederherstellen** zeigt zuerst eine Vorschau.
Erst **Speichern** uebernimmt sie; **Abbrechen** behaelt deine bisherige Ansicht.

Die Kacheln zeigen nur Daten, die du im jeweiligen Bereich sehen darfst. Ein
Pinnwand-Zaehler gibt keine geschuetzten Inhalte einer referenzierten Quelle frei.
