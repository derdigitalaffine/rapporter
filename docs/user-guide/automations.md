# Automationen: Wenn → Dann

Mit Automationen lässt du FamilyOS auf bestimmte Ereignisse reagieren.

Das Prinzip ist immer:

**Wenn etwas passiert → dann soll FamilyOS etwas tun.**

Owner und Erwachsene können Regeln in der App anlegen.

## Ein einfaches Beispiel

**Wenn** morgen Restmüll abgeholt wird  
**Dann** erstelle eine Aufgabe: „Mülltonne rausstellen“.

Weitere mögliche Auslöser sind – je nach verbundenen Daten – zum Beispiel:

- Wetter wie Frost oder Regen,
- amtliche Warnungen,
- Termine,
- Zustände aus Home Assistant,
- ÖPNV-Verspätungen,
- erledigte Aufgaben.

Mögliche Aktionen können unter anderem sein:

- Aufgabe anlegen,
- Einkaufsartikel anlegen,
- Hinweis in der Inbox erzeugen,
- Home-Assistant-Service auslösen,
- Web-Push senden.

## Regel anlegen

1. Öffne **Mehr → Wenn → Dann** bzw. **Automationen**.
2. Wähle eine Vorlage oder beginne mit einer eigenen Regel.
3. Lege den Auslöser fest.
4. Lege die gewünschte Aktion fest.
5. Prüfe die Angaben.
6. Aktiviere die Regel.

## Erst einfach anfangen

Baue zuerst eine kleine Regel, deren Ergebnis du leicht erkennst.

Beispiel: Eine Aufgabe erzeugen ist zum Testen meist übersichtlicher als mehrere Aktionen gleichzeitig auszulösen.

## Wenn eine Regel nicht läuft

Prüfe:

- Ist die Regel aktiviert?
- Ist die benötigte Integration verbunden?
- Ist die betreffende Familie aktiv?
- Sind Push-Benachrichtigungen auf deinem Gerät aktiviert, falls die Aktion Push senden soll?
