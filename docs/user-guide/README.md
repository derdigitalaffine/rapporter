# FamilyOS – Anwenderhandbuch

Dieses Handbuch richtet sich an Familienmitglieder, die **FamilyOS im Alltag verwenden**. Installation, Serverbetrieb, Docker, TLS und Backups sind bewusst nicht Teil dieses Handbuchs; diese Themen bleiben in der technischen Repository-Dokumentation.

> **Stand:** Dieses Anwenderhandbuch wird schrittweise ausgebaut. Es beschreibt nur Funktionen, die im Produkt bereits vorhanden sind.

## Schnell einsteigen

Neu bei FamilyOS? Beginne mit **[Erste Schritte](getting-started.md)**.

Dort erfährst du unter anderem:

- wie du dich anmeldest bzw. einer Familie beitrittst,
- wie die Hauptnavigation aufgebaut ist,
- wie du zwischen Familien wechselst, falls du mehreren angehörst,
- was Online-/Offline-Status bedeuten,
- wie du FamilyOS als PWA auf deinem Gerät nutzt.

## So ist das Handbuch aufgebaut

Die Kapitel folgen möglichst demselben Muster:

1. **Wofür ist die Funktion gedacht?**
2. **Wo finde ich sie?**
3. **Wie erledige ich eine typische Aufgabe?**
4. **Welche Rechte oder Voraussetzungen brauche ich?**
5. **Was passiert offline oder bei externen Datenquellen?**
6. **Was kann ich tun, wenn etwas nicht klappt?**

UI-Bezeichnungen werden so verwendet, wie sie in der deutschen FamilyOS-Oberfläche erscheinen. Technische Begriffe werden nur eingesetzt, wenn sie für die Bedienung wirklich nötig sind.

## Wichtige Grundprinzipien

### Eine Familie ist ein eigener Bereich

Daten wie Aufgaben, Einkäufe, Termine und Integrationen gehören immer zu einer konkreten Familie. Wenn du mehreren Familien angehörst, achte deshalb darauf, welche Familie oben in der App aktiv ist.

### Deine Rolle beeinflusst, was du ändern darfst

Nicht jedes Familienmitglied kann jede Einstellung verändern. Besonders Mitgliederverwaltung, Integrationen und andere gemeinsame Einstellungen können von deiner Rolle und zusätzlichen Berechtigungen abhängen.

### Externe Daten können nur lesbar sein

Einträge aus verbundenen Kalendern oder anderen externen Quellen können **read-only** sein. In diesem Fall änderst du die Quelle beim jeweiligen Anbieter statt direkt in FamilyOS.

### FamilyOS ist für mobile Nutzung und PWA ausgelegt

FamilyOS kann im Browser verwendet und – sofern dein Browser es unterstützt – als Progressive Web App installiert werden. Teile der App funktionieren auch bei instabiler Verbindung; Änderungen werden je nach Bereich später synchronisiert.
