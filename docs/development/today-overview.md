# Today Overview

Delivery: #412 under #223, following the owner interview recorded on #412/#223.

Fresh and explicitly reset layouts use the overview plus a compact Important
section (at most three existing ranked Actions/calendar warnings). The fixed
Situation anchor only adds concrete overlaps or partial-source warnings in this
mode; it does not repeat all tile counts. Without the overview, saved layouts keep
the full Situation/Top 3 experience. Existing v1/v2 layouts retain order,
visibility, settings and revision; overview is appended hidden, never auto-enabled.

The five core tiles use existing authorized sources: the shared paginated Today
Action projection, the shared calendar read, dashboard aggregates for visible open
shopping items and visible pin shells, and the existing Messenger unread state.
Pin counts include authorized neutral unavailable shells, not source previews.
No hidden source content or album/media projection is added. Shopping counts
exclude surprise items hidden from the viewer, checked items and archived/private
lists. Unknown/failed sources show an unavailable value, not a fabricated zero.
The All areas tile uses the existing More route. Capability-bearing domains remain
optional existing widgets, not invented counters or eager new module reads.

Greeting consumes the already loaded member/session. Loyalty only fetches after
its widget mounts; Today no longer performs a second legacy Inbox/session fetch.
Feature links and card selectors use the central Navigation Service/Registry.
There are no new overlays or headless primitives: #771 and #753 wrappers remain
authoritative. Existing customization keeps its Save/Cancel/conflict lifecycle.

Rollback is code-only: no database migration or destructive data conversion.
Removing overview later leaves unknown presentation metadata recoverable by the
registry; original domain objects and personal saved rows are not rewritten on GET.
